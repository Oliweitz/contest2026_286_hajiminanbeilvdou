《开发方案简介》补充说明——基于 openvela 系统的落地方案与核心创新点
（黄山派 AI Agent 参赛项目《随身 AI 腕上管家》· 提交截止 2026-09-20）

一、本文件定位

《开发方案简介.txt》给出开发板选型、一句话定位与总体技术方案；本说明补充两点：方案在 openvela 系统上如何落地、核心创新点是什么。以下为向老师口头说明的缩略版（约 200 字），完整技术细节见《openvela-AI-Agent参赛项目-完整开发报告.md》。

二、向老师说明（约 200 字）

老师，我们的思路是：板子上已驱动的显示、触摸、USB、RTC 直接用；ai_agent 框架自带的主动任务引擎、工具和 MiMo 大模型也直接用。唯一要补的是音频驱动——板上有麦克风和功放，系统却没有对应驱动，我们仿现成样板自写约千行封装，把端侧语音链路跑通；另用 TFLite Micro 做离线命令词唤醒，断网也能演示。执行动作都是真实的：定时任务落盘、文件读写、振动播报。主动场景做了四类：定时简报、久坐提醒、消息播报、活动建议，并留两级保底，保证截止前必有成品。

三、四周节奏

W1（8/21-27）固件跑通 + MiMo CLI 对话 + 音频驱动开工（关键路径 D4-D7）
W2（8/28-9/3）端侧语音闭环 + 语音建提醒到点主动播报（赛题核心演示）
W3（9/4-10）KWS + 每日简报 + 久坐提醒 + LVGL UI
W4（9/11-17）记忆 / 端端协作 + 演示视频 + 场景说明文档
收尾（9/18-20）提交专属仓（含 AI Coding 日志）
